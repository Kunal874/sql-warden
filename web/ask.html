Local demo page for a guarded, read-only text-to-SQL run.

Run states

  • loading
  • overload
  • model-unavailable
  • interrupted
  • empty
  • truncated
  • blocked
  • abstained

Safe flow

  1. Submit one bounded natural-language question.
  2. Use a bearer capability for status, events, continue and cancel actions.
  3. Render text only; never inject model HTML.
